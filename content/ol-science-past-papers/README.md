# G.C.E. O/L Science past-paper MCQs: 2024(2025) and 2025(2026)

Paper I (MCQ) questions from the two English-medium G.C.E. O/L Science examinations, ready to import.

| File | What it is |
| --- | --- |
| `ol-science-past-papers.xlsx` / `.csv` | **68 questions** in the platform's import format (same content in both files) |
| `MANUAL.md` + `figures/` | 10 more questions that need a picture, to add in the question editor |
| `build.py` | The source of the two import files; edit questions here, then run `python3 build.py` |

- **Answers** are from the official answer keys for both papers.
- **Explanations and key points** were written for this platform; each explanation ends with its source (paper and
  question number).
- **Tags:** every question has `past paper`, `ol 2024` or `ol 2025`, and `paper 2024 q12`-style tags for finding it.
- **Formulas** use the platform's LaTeX support (Phase 12).

## Upload (about 15 minutes)

1. **Create the exam.** Admin → Exams → New exam, for example "G.C.E. O/L Science – Past Papers", category
   G.C.E. Ordinary Level.
2. **Structure step.** Add three subjects, **Biology**, **Chemistry** and **Physics**, and under each the topics
   below. Type each name exactly; case and extra spaces don't matter, but spelling does.
3. **Questions step → Import from Excel or CSV.** Choose `ol-science-past-papers.xlsx`.
   - The check should show **68 valid rows and no errors**.
   - If a row says "No active topic", that topic name is missing or misspelt in step 2. Fix it and upload again.
   - Then press **Import 68 question(s) as drafts**.
4. **Publish the questions.** Imported questions start as drafts; publish them in the question bank (filter by the
   tag `past paper`).
5. **Optional:** add the 10 figure questions from `MANUAL.md`.
6. **Exam types, then publish the exam.** Set Practice, Mock and Adaptive; with 68–78 questions a 40-question,
   60-minute mock matches the real paper.

## What was adapted

- **Figures turned into words.** Six questions had a figure that could be described in words without changing the
  question: 2024 Q15, Q17, Q24 and Q34, and 2025 Q3 and Q29.
- **Tables turned into option text.** For 2024 Q30 and 2025 Q13, each option spells out its table row.
- **2024 Q5 (italics).** The answer depends on italics, so the options use formula italics, and the two non-italic
  options say "(not in italics)".
- **Keys that accepted every answer.** The official key accepted all answers for 2024 Q1 and Q29. These files use
  the scientifically correct one: Q1 (4) and Q29 (2).
- **Spelling.** A few spelling slips in the papers were corrected, for example "eusinophils" to "eosinophils".
